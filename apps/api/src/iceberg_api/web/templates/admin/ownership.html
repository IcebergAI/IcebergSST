Ownership

Who is accountable for a finding, and how long they have. Routing gives an unowned finding an owner at the next scan; once it has one it is never re-routed, and once a person sets the owner by hand no rule touches it again. Changing anything here decides what happens to findings from now on — it never reassigns a queue somebody is already working.

Response targets

How long a finding of each severity may stay open before it is overdue. The clock starts when a finding opens and restarts if a resolved secret comes back. Changing a target applies to findings that open from then on — dates already set are left alone, so tightening a target never retroactively declares closed work to have been late.
