# Support

IcebergSST is self-hosted software. The repository provides documentation, reproducible tests,
and issue-based community support; it does not include an uptime or response-time commitment.

Before opening a support issue:

1. Check [`docs/README.md`](docs/README.md), [`docs/deployment.md`](docs/deployment.md), and the
   relevant runbook.
2. Reproduce on the current default branch or a supported release.
3. Remove credentials, source content, tokens, cookies, and plaintext canaries from logs and
   attachments.
4. Include deployment mode, version/commit, command, sanitized error type, and the smallest
   useful reproduction.

Use the private security-reporting path in [`SECURITY.md`](SECURITY.md) for vulnerabilities. Do
not use a public issue for a secret disclosure.
